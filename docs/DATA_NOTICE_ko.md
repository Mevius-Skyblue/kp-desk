# 데이터 고지

> 공개 자료로 만든 모델 결과이며 가격 제시·투자 권유가 아닙니다. 모든 숫자는 기준일 한 날짜의 스냅샷입니다(기준일은 앱 맨 위·견본 첫 블록). English: [DATA_NOTICE_en.md](DATA_NOTICE_en.md)

## 쓴 자료

| 자료 | 쓴 것 | 이 저장소에 있는 형태 |
|---|---|---|
| DART (금융감독원 전자공시, OpenDART) | 채무증권 발행실적, 사채 주석, 주요사항보고서, 재무제표 | 발행 조건 숫자와 공시 원문 링크(`https://dart.fss.or.kr/dsaf001/main.do?rcpNo=…`). 견본 품의서의 재무 숫자 |
| SEC EDGAR (미국 증권거래위원회) | 정책기관·국가의 영문 발행 서류(발행 조건) | 발행 조건 숫자와 서류 URL |
| 미국 재무부 (Daily Treasury Par Yield Curve Rates) | 기준일 par 수익률 커브 | `app/data/curve.csv` (기준일 하루치) |
| 한국은행 ECOS | 업종 통계(견본 품의서의 업종 비교) | 견본 파일 안의 집계 숫자 |
| 보도 | 발행 규모·쿠폰·최종 스프레드 등 **숫자 사실** | 숫자와 기사 URL만. **기사 문장은 저장·전재하지 않는다.** 기사 저작권은 각 언론사에 있다 |

앱 ③의 비교 사례 목록 `app/data/fair_spread_comps.csv`는 추정마다 엔진이 쓴 비교 사례 번호(발행사 id·만기 + `deals.csv`의 `deal_key`)만 담는다. 숫자 칸은 없고, 화면은 스프레드·발행일·출처를 `deals.csv`에서 붙여 보인다. 기준일 전 18개월 기간은 공개 칸이 아닌 가격결정일 기준이라 공개 칸만으로는 같은 목록을 다시 고를 수 없으므로, 목록 자체를 싣는다.

## 쓰지 않은 자료

- **ICE BofA 지수(FRED 제공)**: 이 저장소·앱·견본에 **없다.** 지수 값·수준·변화를 싣지 않는다. 비공개 내부 분석(내부 모드)에서만 썼고, 공개 문서에는 그 모드의 오차 통계만 적는다
- 비공개 정보: 어떤 기관의 내부 문서나 공개되지 않은 정보도 쓰지 않았다
- 시세 단말기·유료 데이터베이스 자료

## 표시

- **가상 장부(실제 보유 아님)**: 견본의 장부는 공개 사례에서 규칙으로 뽑은 예시이며 어떤 기관의 실제 보유·평가가 아니다
- 견본 품의서·1쪽 요약·피치북·MI 대시보드는 공개 자료로 자동 생성한 초안이며 가상 거래를 쓴다
- 모델 추정 범위는 공개 자료로 만든 모델 결과이며 가격 제시·투자 권유가 아니다

## 비공개 원본 저장소 경로

견본의 출처 칸과 버전 줄에 나오는 파일 경로(`config/…`, `data/…`, `reports/…`, `scripts/…`)와 단계 이름은 이 공개 패키지를 만든 비공개 원본 저장소 기준이며, 이 저장소에는 그 파일이 없다.

## 정확성

공개 자료를 옮기는 과정의 오류, 출처 자체의 정정, 통화·금액 추정의 한계가 있을 수 있다(자세히: [알려진 한계](KNOWN_ISSUES_ko.md)). 각 행의 출처 링크로 원문을 확인할 수 있다. 오류를 발견하면 저장소 이슈로 알려 주면 확인한다.
