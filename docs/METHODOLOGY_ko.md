# 방법론

> 공개 자료로 만든 모델 결과이며 가격 제시·투자 권유가 아닙니다. 숫자는 기준일 한 날짜의 스냅샷입니다(기준일은 앱 맨 위·견본 첫 블록). English: [METHODOLOGY_en.md](METHODOLOGY_en.md)

## 1. 데이터

| 항목 | 내용 |
|---|---|
| 출처 | DART(전자공시: 채무증권 발행실적·사채 주석·주요사항보고서), SEC EDGAR(정책기관·국가의 영문 발행 서류), 미국 재무부 par 수익률 커브, 보도에 나온 **숫자와 URL만**(기사 문장은 저장하지 않음). 자세한 조건은 [데이터 고지](DATA_NOTICE_ko.md) |
| 단위 | 1행 = 1 트랜치. 같은 채권이 여러 출처에 나오면 하나로 합치고, 칸마다 우선순위(SEC → DART → 보도)를 둔다 |
| 발행사 | 별칭 표로 같은 발행 주체를 묶는다(지점은 본점 은행). 유형: 국가·정책금융기관·공기업·은행·카드·캐피탈·기타 금융·비금융 기업·보증채 발행사. 영문 이름은 별칭 표, 없으면 DART 기업 영문명 또는 회사 공식 영문명(이름마다 출처 기록) |
| 비교 키 | 앱 스냅샷은 발행사 코드·통화·발행일·만기로 만든 안정 키(`deal_key`, 영문·숫자만, 같은 키가 겹치면 원천 키 순서로 `n1`·`n2` …)만 쓴다. 견본(품의서·피치북·가상 장부 등)에는 기준일 빌드의 내부 참조 번호(K#####)가 나오는데, 빌드 위치 번호라 재빌드 때 바뀌므로 앱의 키와 직접 맞춰 볼 수 없다([알려진 한계](KNOWN_ISSUES_ko.md) KI-14) |

### 표본 등급

| 등급 | 정의 | 쓰임 |
|---|---|---|
| A | 통화 확인(SEC·보도·DART 원문) + 발행 수익률 | 주 표본 |
| B | 통화 확인 + 쿠폰만(발행 수익률 없음) | 주 표본(쿠폰 기준 보정) |
| S | 통화 확인 + 보도 최종 스프레드(미국채 기준), 수익률·쿠폰 없음 | 주 표본 |
| C | DART 금액으로 추정한 통화(검증 통과) | 참고·민감도만 |
| D | 제외: 김치본드·디지털 채권·주식 연계·USD 외 통화·변동금리·1년 미만·스프레드 없음 등 | 비교표에 없음 |

### 채권 성격 (비교표)
공시·보도의 채권 조건(선순위 여부·보증)으로만 나눈다: 커버드본드 → 후순위·신종자본(후순위·하이브리드·Tier) → 보증 → 선순위 무보증 순으로 먼저 맞는 것. 비교표 기본 화면은 선순위 무보증만 보여 주고, 다른 성격은 필터에서 켤 수 있다. 계산은 바뀌지 않는다(분류 표시만).

### 대표 스프레드
미국채 대비 bp. 발행 수익률이 있으면 그것으로(같은 만기의 미국채 par 수익률을 보간해 뺀 값), 없으면 보도 최종 스프레드, 그것도 없으면 쿠폰으로 계산한다. 쿠폰 기준은 발행 수익률 기준보다 낮게 나오는 경향이 있어, 모델 평가에서는 개발 기간에 정한 상수(−7.59bp, 개발 기간 35건 중앙값)로 쿠폰 기준 값을 보정했다. 비교표의 숫자는 보정 전 대표 스프레드다.

## 2. 채권 엔진 (`src/bond/`)

| 항목 | 규칙 |
|---|---|
| 관행 | USD: 30/360(미국 채권 기준), 연 2회 이자. EUR: Act/Act(ICMA), 연 1회. 미국채: Act/Act(ICMA), 연 2회 |
| 수익률 | 쿠폰 횟수로 복리하는 시장 관행 수익률: 더티 가격 = Σ 현금흐름 / (1 + y/f)^(기간 수) |
| 이자 일정 | 만기에서 12/f개월씩 거꾸로 만든다. 첫 기간은 짧을 수 있다. 영업일 조정·공휴일 달력·월말 규칙은 없다([알려진 한계](KNOWN_ISSUES_ko.md)) |
| 경과이자·결제 금액 | 직전 이자일(첫 기간이면 발행일)부터 결제일까지. 결제 금액 = (깨끗한 가격 + 경과이자) × 액면/100 |
| 위험 지표 | 매콜리·수정 듀레이션, 볼록성, DV01(수익률 1bp 상승 시 가격 하락액) |
| 커브 | 재무부 par 수익률을 만기 사이 선형 보간(양 끝 밖은 평평하게). 결제일을 기준점으로 6개월 격자(최소 30년)에서 "par 채권 가격 = 100" 조건으로 할인계수를 차례로 풀고(부트스트랩), 격자 사이는 할인계수의 로그를 선형 보간 |
| G-스프레드 | 채권 수익률 − 같은 남은 만기의 보간 par 수익률 |
| Z-스프레드 | 제로 커브의 모든 점(반기 복리)에 같은 값을 더해 할인한 가격이 시장 더티 가격과 같아지는 값 |

엔진은 데이터베이스·네트워크를 쓰지 않는 순수 함수이며, 앱 ① 계산기는 이 함수를 그대로 부른다(새 공식 없음). 독립 대조 결과는 [검증 결과](VALIDATION_ko.md).

## 3. 적정 스프레드 범위 (공개 모드, 앱 ③)

공개 화면에는 **공개 모드의 대표 출력인 N0 기준선**만 싣는다.

1. **비교 집합**: 주 표본(A·B·S) 중 기준일 전에 가격이 정해진 사례(시장 자료는 기준일 전날까지). 쿠폰 기준 값은 위 상수로 보정
2. **발행사 프로필**: 그 발행사의 기준일 전 마지막 "선순위 무담보·보증 없음" 사례에서 유형과 등급 구간을 읽는다(커버드본드·후순위·보증채의 등급은 쓰지 않음)
3. **점 추정**: 같은 유형 묶음(국가·정책 / 공기업 / 은행 / 금융 / 비금융)과 같은 등급 구간(AAA·AA·A·BBB·BB·없음)에서 기준일 전 18개월 동안 나온 사례 스프레드의 중앙값. 없으면 같은 유형(등급 무관), 그다음 전체 표본(앱의 "비교 묶음"이 이 단계)
4. **범위**: 점 추정 − Q3(e) ~ 점 추정 − Q1(e). e = 개발 기간 N0 오차(예측 − 실제, 주 표본)의 1·3사분위. 그래서 범위 폭은 모든 발행사에서 같고, N0는 만기를 쓰지 않으므로 같은 발행사의 3·5·7·10년 값이 같다

앱의 표(`app/data/fair_spread.csv`)는 엔진 함수를 기준일로 그대로 부른 결과이며, 새 계산이 아니다.

비교 사례 목록(`app/data/fair_spread_comps.csv`)은 같은 엔진 호출이 돌려준 비교 사례를 `deal_key`로 옮긴 것이다. 모든 행에서 목록의 대표 스프레드(`deals.csv`) 중앙값이 점 추정과 같고(±0.01bp), 건수가 화면의 비교 사례 건수와 같다. 18개월 기간은 가격결정일 기준이고 가격결정일은 공개 칸이 아니어서(발행일이 빈 보도 사례도 있다), `deals.csv`의 칸만으로는 같은 목록을 다시 고를 수 없다.

## 4. 규칙 선택과 검증 방식

- **사전 고정**: 규칙·표본·판정 기준을 설정 파일로 먼저 커밋하고 결과를 그 뒤에 만들었다. 결과를 본 뒤 고친 것은 같은 파일에 이유와 함께 덧붙였다
- **기간 분리**: 개발 기간(가격 결정일 2025-06-30까지)에서만 후보 규칙을 비교·선택했다. 그 뒤 기간(홀드아웃)은 잠가 두었다가 **한 번만** 평가했고 다시 실행하지 않는다
- **후보**: 공개 모드 후보는 KPD 자체 지수(공개 사례 스프레드 중앙값의 이동)와 발행사 이력·비교 사례를 쓰는 규칙들. 내부 모드 후보는 ICE BofA 지수를 쓰며 내부 분석 전용이다(값은 공개하지 않고 오차 통계만)
- **판정**: 평균 절대 오차(MAE)가 N0보다 작고, 짝지은 부트스트랩(2,000회) 95% 구간 상단이 0보다 작을 때만 "기준선보다 낫다". 공개 모드 후보는 개발 기간에 이 기준을 넘지 못했고 홀드아웃에서도 N0보다 나았다고 할 수 없었다 → 공개 대표 출력 = N0
- **감사**: 구현에 참여하지 않은 별도 감사가 채권 엔진(QuantLib 재계산), 가상 장부 평가(손계산), 홀드아웃 실행 기록, 출력(엑셀 ↔ 엔진)을 따로 확인했다

## 5. 가상 장부와 견본

- **가상 장부(실제 보유 아님)**: 공개 사례 중에서 정해진 규칙과 난수 씨앗으로 뽑은 예시 장부다. 기준일 커브로 다시 평가하고 손익을 캐리·금리·스프레드·잔차로 나눈다
- **견본**: 여신 품의서·1쪽 요약(PDF), 피치북·가상 장부 평가·MI 대시보드(엑셀), 한/영. 공개 자료로 자동 생성한 초안이며 가상 거래를 쓴다. 엑셀은 수식이 살아 있고 MasterCheck 칸이 자체 점검을 보여 준다
- 앱에 없는 것: 내부 모드(ICE) 값, 일별 갱신, 문서 생성, 대출 화면, 점수표 화면
